Fernet Encryption

Note content is encrypted using AES-128 in CBC mode with PKCS7 padding and authenticated via HMAC-SHA256. Plaintext never touches SQLite disk storage.

Strict Ownership Access

Every database query and API endpoint explicitly verifies note ownership. User B cannot view, edit, or delete User A's notes even if they know the ID.

REST API & Fetch

Includes Django REST Framework API endpoints with strict authentication, paired with Vanilla JavaScript Fetch API for real-time dashboard updates without page reload.
